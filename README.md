# エネルギー記録

活動ごとの「夢中度」と「エネルギー」を、端末の中だけで記録する PWA。
仕様は `energy-log-plan.md`（リポジトリのひとつ上）を参照。

実装済み：**M1（記録の核）** と **M2（スマホで使える形）**。
振り返りタブ（M3）は、データが3〜4週たまってから作ります。

## 動かす

依存ライブラリもビルドも不要です。ただし Service Worker と IndexedDB のために、
ファイルを直接開く（`file://`）のではなく HTTP で配信してください。

```sh
cd energy-log
python -m http.server 8000
# → http://localhost:8000 を開く
```

VS Code の Live Server 拡張でも同じです。

## テスト

```sh
cd energy-log
node --test          # Node 18以上。追加インストールなし
```

`tests/dates.test.js` と `tests/io.test.js`（日付キー、メモ解析、CSV、インポートの統合規則）。

## 公開する

1. GitHub にリポジトリを作り、この `energy-log/` の中身をルートに push する
2. Settings → Pages → Branch: `main` / `(root)`
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される（HTTPS は自動）

パスはすべて相対にしてあるので、サブディレクトリ配信でも動きます。

### ホーム画面に追加する

- **iPhone**：ブラウザで開く → 共有 → 「ホーム画面に追加」。
  **必ずアイコンから開いてください。** ブラウザのタブから開くと保存先が別扱いになり、
  記録が見えません（スマホのタブで開くと警告バナーが出ます）。
- **Android**：Chrome のメニュー → 「アプリをインストール」。

### iPhone で Chrome を使っている場合

iOS はどのブラウザも中身が WebKit なので、**Chrome でも Safari でも挙動は同じ**です。
ホーム画面に追加したあとはブラウザを経由しないので、普段づかいには影響しません。

ただし iOS のバージョンによっては、Chrome の「ホーム画面に追加」が
**ただのショートカット**（開くとブラウザが立ち上がる）になることがあります。
追加したアイコンを開いてアドレスバーが出たらそれなので、その場合だけ Safari で追加し直してください。
アドレスバーが出なければ成功です。

どちらも決まった時刻の通知は出せません。標準の「リマインダー」や時計アプリのアラームで、
毎晩21:30に繰り返し通知を設定して代用してください。

## 使い方のメモ

- 時間帯は自動判定しません。保存するたびに次の時間帯（朝→午前→午後→夕方→夜）へ進みます。
  最後に使った時間帯は覚えていて、次に開いたときそこから始まります。
- 翌朝に書くときは「昨日」を1タップ。
- 書くことがない日は「山と谷だけ書く」に切り替えて、山・谷・平坦だけ残します。
- **週1回、設定タブから JSON をエクスポート**してバックアップしてください。
  7日以上たつと記録タブの上に催促が出ます。

## データについて

- 記録は端末の IndexedDB（DB名 `energy-log`, v1）だけに入ります。外には出ません。
- CSP の `connect-src 'none'` で、ページからの外部通信をコードレベルで禁止しています。
- エクスポートした JSON / CSV は `.gitignore` 済みです。コミットしないでください。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（4タブ） |
| `styles.css` | 見た目。ダークモード対応、タップ対象44px以上 |
| `app.js` | 画面切り替え・フォーム・描画 |
| `db.js` | IndexedDB の薄いラッパー |
| `io.js` | エクスポート／インポート／メモ取り込み |
| `dates.js` | ローカル日付ユーティリティ |
| `sw.js` | Service Worker（オフライン用キャッシュ） |

CSP のため、インラインの `<script>`、`onclick=""`、HTML の `style=""` は使っていません。
イベントは `addEventListener`、見た目の切り替えは `classList` で行っています。

## リリースのとき

`sw.js` の `CACHE = 'energy-log-v2'` の番号を上げてください。上げないと古いファイルが残ります。
